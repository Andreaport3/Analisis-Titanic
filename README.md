# Analisis-Titanic# Proyecto Kaggle


Bienvenido/a al repositorio del proyecto **Análisis Titanic**. En este proyecto se realiza un análisis exploratorio de datos (EDA), limpieza y modelado predictivo utilizando el dataset clásico de la competición de [Kaggle: Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic).

---

##  Objetivo del Proyecto

El objetivo principal es analizar qué variables influyeron en la supervivencia de los pasajeros del Titanic y construir un modelo de Machine Learning capaz de predecir si un pasajero sobrevivió o no al naufragio.

---

##  Estructura del Repositorio

* `Analisis-titanic.ipynb`: Notebook principal con el desarrollo del análisis, gráficos y entrenamiento del modelo.
* `datos_limpios.csv`: Dataset procesado tras las etapas de limpieza y transformación de variables.
* `requirements.txt`: Lista de librerías y dependencias necesarias para ejecutar el proyecto.

---

##  Tecnologías y Librerías Utilizadas

* **Lenguaje:** Python 3.x
* **Análisis y Manipulación de Datos:** Pandas, NumPy
* **Visualización:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
